# RFID-Based Attendance Monitoring System with AES Encryption and Intrusion Detection Algorithm

## Project Overview

This project is an **RFID-Based Attendance Monitoring System** developed to address the common issues associated with traditional manual attendance monitoring.

Manual attendance methods can be time-consuming and may result in inconsistencies, proxy attendance, inaccurate records, and limited real-time monitoring. This system provides a digital approach to attendance management by using **RFID technology** to improve the accuracy, efficiency, and security of attendance data.

## Purpose

The system aims to provide a more reliable and efficient way of recording and monitoring attendance by reducing the limitations of manual attendance processes.

## Problem Addressed

Traditional attendance monitoring may involve:

- ⏱️ Time-consuming manual recording
- ❌ Inconsistent or inaccurate attendance data
- 👥 Possibility of proxy attendance
- 📄 Risk of lost or misplaced records
- 📊 Limited access to real-time attendance information
- 🔐 Security concerns in attendance management

The proposed RFID-based system aims to provide a centralized digital solution for recording, monitoring, and managing attendance.

### Key Objectives

- Reduce the time required for attendance recording
- Minimize errors and inconsistencies in attendance records
- Help prevent proxy attendance
- Provide faster access to attendance information
- Improve the accuracy and security of attendance data
- Support real-time attendance monitoring

## Key Features

- RFID-based attendance scanning
- Student registration and RFID card assignment
- Attendance record management
- Real-time attendance monitoring
- Attendance status tracking
- User authentication and role-based access
- Secure storage of attendance records
- Monitoring of unauthorized or invalid attendance attempts
- Advanced Encryption Standard (AES)
- Intrusion Detection

## Technologies Used

- PHP
- MySQL / MariaDB

- CSS
- JavaScript
- XAMPP
- RFID Technology
  > RC522 RFID Module
  > ESP8266MOD 

## Project Context

This system was developed as an academic/capstone project to demonstrate how RFID technology can be applied to improve attendance management in an educational environment.

## Expected Outcome

The system aims to make attendance monitoring **faster, more accurate, efficient, and secure**, while providing authorized users with easier access to attendance records and monitoring information.
